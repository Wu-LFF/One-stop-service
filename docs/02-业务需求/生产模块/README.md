# 生产通 — 业务需求

> 来源：03一站平台各板块流程明细_业务提供.xlsx → 生产流程明细

## 功能列表

| # | 功能 | 说明 | 系统对接 |
|---|------|------|:-------:|
| 1 | [MES报工](MES报工.md) | 员工报账（冲裁段、针车支流等），服装板块 | ✅ MES |
| 2 | [报工确认](报工确认.md) | 员工提交→班组长确认→课长审核 | ✅ MES |
| 3 | [报工审核](报工审核.md) | 生管经理终审，异常数据驳回 | ✅ MES |
| 4 | [仓库扫描](仓库扫描.md) | 物料/成品出入库扫码，库存实时同步 | ✅ MES |
| 5 | [报工明细查询](报工明细查询.md) | 按时间/工序查询报工记录 | ✅ MES |
| 6 | [件资查询](件资查询.md) | 工序明细、单价、工资明细查询 | ✅ MES |
| 7 | [样鞋管理](样鞋管理.md) | 样鞋制作/入库/领用/报废全流程 | ❌ |
| 8 | [件资异常上报](件资异常上报.md) | 生产异常直接上报给直接上级 | ❌ |
| 9 | [员工意见箱](员工意见箱.md) | 反馈意见给直接上级 | ❌ |

> 生产通主要依赖MES现有系统，平台侧负责统一入口和查询展示
