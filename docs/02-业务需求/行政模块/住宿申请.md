# 住宿申请

## 功能说明
员工在线申请住宿、调换宿舍、退宿，告别纸质填表。

覆盖三种场景：
1. **住宿申请** — 新员工/新入住
2. **调换申请** — 换宿舍
3. **退宿申请** — 退宿舍

## 审批流程

**住宿申请**：`员工发起 → 宿管审核 → 后勤课长审批`

**调换申请**：`员工发起 → 宿管审核 → 后勤课长审批`

**退宿申请**：`员工发起 → 宿管审批`

## 关键字段

| 场景 | 字段 |
|------|------|
| 住宿 | 姓名、工号、电话、身份证、中心/系统、职务、水电度数（宿管填写）、楼栋房号（宿管匹配） |
| 调换宿舍 | 姓名、工号、电话、现住楼栋号、意向楼栋号、备注（调换原因） |
| 退宿 | 姓名、工号、楼栋号、电表度数（上传电表照片） |
