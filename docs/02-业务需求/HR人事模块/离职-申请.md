# 离职-申请

## 功能说明

员工线上提交离职申请，跟进离职流程的审批，减少线下找各环节负责人审批。

**提醒规则**：离职时间提前3天对人事专员进行提醒。

## 审批流程

```
员工发起 → 直接上级 → 部门经理 → 人资BP负责人 → 工厂/中心负责人
                                          ↓
                                  （抄送给到人事专员）
```

## 关键字段

姓名、工号、入司时间、计划离职时间、离职原因、具体原因、最后工作日

## 系统对接

- **夏谷系统**：【人员管理-人事异动】
