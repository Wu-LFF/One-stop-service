# 人事通 — 业务需求

> 来源：03一站平台各板块流程明细_业务提供.xlsx → HR流程明细

## 功能列表

| # | 功能 | 流程摘要 | 夏谷对接 |
|---|------|---------|:-------:|
| 1 | [补卡](补卡.md) | 员工→直接上级审批 | ✅ |
| 2 | [请假](请假.md) | 员工→直接上级+间接上级+直属领导（按天数分层） | ✅ |
| 3 | [销假](销假.md) | 员工→直接上级→抄送人事专员 | ✅ |
| 4 | [入职指引](入职指引.md) | 含报餐、住宿申请联动 | ❌ |
| 5 | [调动](调动.md) | 工厂内/跨工厂多级审批 | ✅ |
| 6 | [离职-申请](离职-申请.md) | 员工→逐级审批，提前3天提醒人事专员 | ✅ |
| 7 | [离职-手续办理](离职-手续办理.md) | 人事专员发起→员工确认→窗口办理 | ✅ |
| 8 | [工牌/厂服补领](工牌-厂服补领.md) | 员工→上级→HR→物资发放→确认扣款 | ✅ |
| 9 | [考勤确认](考勤确认.md) | 后台发起→员工确认（1天未确认推上级，3天默认） | ✅ |
| 10 | [扣款确认](扣款确认.md) | 后台发起→员工确认（同上规则） | ✅ |
| 11 | [工资确认](工资确认.md) | 后台发起→员工确认（同上规则） | ✅ |
| 12 | [考勤查询](考勤查询.md) | 自助查询 | ✅ |
| 13 | [工资查询](工资查询.md) | 自助查询（含奖惩） | ✅ |
| 14 | [福利券](福利券.md) | 2028年上线 | ❌ |

## 待确认事项

- 未打卡提醒规则（几天提醒一次）
- 未及时确认（工资/考勤/扣款）逐级推送规则需补充
