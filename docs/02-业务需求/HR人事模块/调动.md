# 调动

## 功能说明

对员工组别、课别、部门或者跨工厂调动，实现线上审批并系统落位。

## 审批流程

### 工厂/中心内调动
```
调出工厂/中心人事专员 → 员工本人确认 → 原直接上级 → 原部门经理
→ 现直接上级 → 现部门经理 → 工厂/中心负责人
```

### 跨工厂/中心调动
```
调出人资BP发起 → 员工本人确认 → 原直接上级 → 原部门经理
→ 原工厂/中心负责人 → 现直接上级 → 现部门经理
→ 调入人资BP负责人 → 现工厂/中心负责人 → 制造人资负责人 → 事业部总经理
```

## 关键字段

同OA管理调动的流程字段一致
