# 请假

## 功能说明

员工事先发起请假流程。临时突发急事未及时请假导致的考勤异常，2-3天推送给员工提醒提交请假。

**时间要求**：每月1号前完成上月补卡（与补卡联动）。

## 审批流程

按请假天数分层审批：

| 天数 | 审批链 |
|------|--------|
| ≤3天 | 直接上级 |
| 3-7天 | 直接上级 + 间接上级 |
| >7天 | 直接上级 + 间接上级 + 间接上级的直属领导 |

- 每个环节审批均限1天内完成
- 超1天未审批 → 提醒该环节审批人

## 关键字段

姓名、工号、请假日期及请假时间段（同OA管理一致）

## 系统对接

- **夏谷系统**：【考勤管理-打卡管理】
