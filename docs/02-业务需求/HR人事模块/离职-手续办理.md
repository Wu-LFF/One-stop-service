# 离职-手续办理

## 功能说明

员工离职审批通过后，到了最后工作日，线上发起离职办理流程，减少线下员工找各环节人员签字确认。

## 审批流程

```
人事专员发起 → 员工确认 → 直接上级确认（材料扣款等）
                                    ↓
                        人资/行政各个窗口人员办理
                    （抄送各工厂薪酬专员）
```

## 关键字段

以离职手续办理单的字段进行处理

## 系统对接

- **夏谷系统**：【薪酬管理】-对应科目的相关扣款
- **电子签章**：手续办理完成后触发电子签章流程
