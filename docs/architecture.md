# 架构设计 — One-stop_service

## 技术选型

- **前端**：飞书（Feishu）统一协同入口 / PC端 + 移动端
- **后端**：若依（RuoYi）流程引擎
- **语言**：Java（后端）/ JavaScript / TypeScript（前端）
- **数据库**：MySQL / Redis
- **部署**：高可用集群部署、支持灾备

## 系统架构

采用 **飞书前端统一协同入口 + 若依后端流程核心引擎** 的双层耦合架构：

```
接入层   统一门户 / PC端 / 移动端 / 统一认证 / 消息中心 / 单点登录
        ┌─────────────────────────────────────────────────────┐
        │  飞书 工作台（统一入口、待办中心、消息中心）         │
        └─────────────────────────────────────────────────────┘
                                │
应用层   核心业务应用 / 流程应用 / 自助服务 / 协同办公 / 工单管理
        ┌─────────────────────────────────────────────────────┐
        │  人事通  │  行政通  │  生产通  │  制造资讯          │
        │  数据服务│  个人中心│  流程与工单模块              │
        └─────────────────────────────────────────────────────┘
                                │
流程层   若依（RuoYi）流程引擎
        ┌─────────────────────────────────────────────────────┐
        │  统一流程引擎 / 表单中心 / 审批配置 / 工单闭环     │
        │  操作日志 / 版本管理 / 数据归档                    │
        └─────────────────────────────────────────────────────┘
                                │
集成层   系统对接
        ┌─────────────────────────────────────────────────────┐
        │  夏谷（HR主数据）  │  暖心宝（生活服务）           │
        │  TMS（安全通行）   │  EAM（设备运维）              │
        │  鞋服 MES（生产数据）│  电子签章                    │
        └─────────────────────────────────────────────────────┘
```

## 六大应用模块

| 模块 | 说明 |
|------|------|
| **统一门户模块** | 统一入口、待办中心、消息中心、公告中心、常用应用导航 |
| **人事服务模块** | 员工全生命周期、考勤、薪酬、异动、审批、自助查询 |
| **行政服务模块** | 宿舍、食堂、放行、访客、其他后勤保障 |
| **生产协同模块** | 报工、报修、件资查询、质量产量预警 |
| **数据与运营模块** | 数据看板、统计分析、业务监控、决策支撑 |
| **流程与工单模块** | 统一流程引擎、表单中心、审批配置、工单闭环、督办考核 |

各模块通过服务化调用交互，不交叉、不重复、不冗余，职责清晰。

## 设计原则

1. **全场景覆盖**：围绕员工日常办公与生产运营核心需求，一站式服务体验
2. **流程引擎驱动**：以流程引擎为核心连接器，实现全链路闭环
3. **数据整合分析**：统一数据汇聚与分析中心，支撑运营决策
4. **轻量化接入**：不颠覆现有业务系统，聚焦前端体验统一与后端流程贯通
5. **分步实施**：基础建设→功能深化→智能升级，三步走稳健推进

## 主数据管理

| 主数据 | 来源系统 | 说明 |
|--------|---------|------|
| 人员主数据 | 夏谷系统 | HR维护，定时同步，本平台仅展示 |
| 组织主数据 | 夏谷系统 | HR维护组织架构，定时同步 |
| 通行数据 | TMS | 物品/人员放行、外来人员通行 |
| 生产数据 | 鞋服 MES | 报工、产量、件资 |
| 生活服务数据 | 暖心宝 | 住宿、报修、水电 |
