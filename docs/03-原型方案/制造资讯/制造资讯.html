消防安全操作规范

安全管理部 · 2026-05-22

一、灭火器使用规范

1. 提——提起灭火器；
2. 拔——拔掉保险销；
3. 握——握住喷管对准火源根部；
4. 压——压下压把喷射灭火。

二、逃生通道指引

各车间设有2条以上安全逃生通道，指示标识为绿色应急灯，请熟记就近逃生路线。

三、应急响应流程

发现火情 → 立即报警（119/厂内安保）→ 启动消防设施 → 组织人员疏散 → 集合点清点人数。
