# 制造资讯 — 原型方案

> 制造资讯是面向全员的信息服务模块，涵盖公告制度、学习园地、互动服务三大板块。

## 涉及角色

| 角色 | 涉及功能 |
|------|---------|
| 全体制造员工 | 公告查阅、制度学习、安全知识、服务指南、提案提交、IT报修 |
| 公告管理员 | 公告发布、分组投放、分级管理 |
| 安全管理部 | 安全小红书内容发布 |
| 部门负责人 | 提案初审、评审立项 |

## 数据字段汇总

| 实体 | 核心字段 |
|------|---------|
| 公告 | 标题、发文单位、发文时间、分类、正文（支持图片/视频）、收件范围、已读人数 |
| 制度 | 标题、版本号、生效日期、失效日期、状态、正文（在线只读）、分类 |
| 安全知识 | 标题、发布单位、发布时间、正文、分类 |
| 服务指南 | 标题、分类、正文（支持视频）、FAQ |
| 提案 | 标题、类型、提案人、提交时间、现状描述、改进方案、预期效益、审批状态、各环节意见 |
| IT报修 | 报修类型、问题描述、所在位置、联系电话、附件 |
