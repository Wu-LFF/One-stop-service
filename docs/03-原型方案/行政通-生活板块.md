## 页面一：生活板块首页（mp-sh-index）

### 布局结构

顶部"生活服务" → 功能入口网格（2列）→ 底部 Tab 导航

### 核心元素

- [ ] **顶部栏**：标题"生活服务"
- [ ] **功能入口卡片**：
  - 🏠 住宿申请（含入住/调换/退宿）
  - 📋 超标住宿申请 → OA 跳转
  - 🔧 宿舍报修
  - 💡 水电查询
  - 🍽️ 报餐
  - 🪪 家属卡申请 → OA 跳转
  - 🚗 车位申请
- [ ] **底部导航**：首页、消息、我的

---

## 页面二：住宿申请首页（mp-sh-zssq）

### 布局结构

顶部"住宿申请" → 三种场景选择卡片 → 底部"我的申请记录"

### 核心元素

- [ ] **场景选择**：
  - 🆕 入住申请（新员工/新入住）
  - 🔄 调换申请（换宿舍）
  - 🚪 退宿申请（退宿舍）
- [ ] **申请记录入口**：查看我的申请记录

---

## 页面三~五：住宿申请表单（mp-sh-zssq-in / change / out）

### 布局结构

顶部标题 → 表单区域 → 提交按钮

### 核心元素

**入住申请：**
- [ ] 基本信息：姓名、工号、电话（自动读取）
- [ ] 身份证号
- [ ] 中心/系统、职务
- [ ] 宿管填写区：水电度数、楼栋房号

**调换申请：**
- [ ] 基本信息：姓名、工号、电话
- [ ] 现住楼栋号
- [ ] 意向楼栋号
- [ ] 调换原因备注

**退宿申请：**
- [ ] 基本信息：姓名、工号
- [ ] 楼栋号
- [ ] 电表度数 + 拍照上传

### 审批流程

- 入住/调换：员工 → 宿管审核 → 后勤课长
- 退宿：员工 → 宿管审批

---

## 页面九~十一：宿舍报修（mp-sh-ssbx / list / detail）

### 布局结构

提交表单 → 报修记录列表 → 详情

### 核心元素

**提交表单：**
- [ ] 报修类型：下拉选择（水电/家具/电器/门窗/其他）
- [ ] 报修描述
- [ ] 拍照上传（最多 3 张）
- [ ] 联系电话（自动读取）

**列表：**
- [ ] 状态过滤：全部/待处理/处理中/已完成
- [ ] 卡片列表：类型、状态、时间

**详情：**
- [ ] 工单进度状态
- [ ] 维修工信息及联系电话
- [ ] 退单原因（如有）

### 审批流程

员工发起 → 工程接单/转单 → 完成
材料不足时：退单（标记材料不足，待补）

---

## 页面十二：水电查询（mp-sh-sdquery）

### 布局结构

顶部"水电查询" → 月度统计卡片 → 明细列表

### 核心元素

- [ ] **月份选择**：切换查询月份
- [ ] **统计卡片**：用水度数、用电度数、应缴总费用
- [ ] **明细列表**：项目、上月度数、本月度数、单价、金额
- [ ] **历史趋势**：近6月用水用电趋势（简易图表模拟）

### 数据字段

月份、工厂、宿舍楼、房间号、水/电度数、单价、总费用、个人费用、各项扣款/奖励

---

## 页面十三：报餐（mp-sh-bc）

### 布局结构

顶部"报餐" → 报餐时段说明 → 日期选择 → 用餐地点 → 提交

### 核心元素

- [ ] **报餐规则提示**：新员工/非新员工不同时间窗口
- [ ] **日期选择**：选择报餐起止日期
- [ ] **用餐地点**：园区食堂/其他
- [ ] **报餐记录**：已报餐日期列表

### 交互说明

- 新员工入职当月只能报到月底
- 非新员工每月 20 号~月底报下月
- 无需审批，提交即生效
