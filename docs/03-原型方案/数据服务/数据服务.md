# 数据服务 — 原型方案

> 数据服务是面向全员的统计分析模块，涵盖个人看板、团队看板、运营分析三大板块。系统自动采集各业务模块数据，提供可视化展示。

## 涉及角色

| 角色 | 涉及功能 |
|------|---------|
| 全体员工 | 个人数据看板（考勤/工资/报工统计） |
| 班组长/课长 | 团队管理看板（班组/部门数据） |
| 生管经理/高管 | 运营分析（园区总览/业务趋势） |

## 数据字段汇总

| 实体 | 核心字段 |
|------|---------|
| 个人考勤 | 应出勤天数、实际出勤、请假天数、旷工天数、迟到/早退次数、出勤率、月度趋势 |
| 个人工资 | 基本工资、计件工资、津贴、奖金、社保、公积金、其他扣款、实发合计、月度趋势 |
| 个人报工 | 月产量、总工时、日均产量、工序分布、日报工趋势 |
| 班组数据 | 产量、出勤人数、人均产量、待确认报工数、成员排行、产量趋势 |
| 部门数据 | 总产量、在岗人数、班组排行、出勤率对比、产量趋势 |
| 运营总览 | 在岗人数、今日产量、月产量、异常笔数、出勤率、人职离职、产量趋势、异常分布 |
