### 页面1：飞书工作台-人事通入口

**布局结构**（飞书移动端首页/PC端应用中心）
- 飞书工作台的应用列表中展示「人事通」应用图标
- 图标 + 应用名称，点击进入

**核心元素**
- 应用图标（人事通Logo）
- 应用名称：人事通
- 待办角标：展示当前待办数量（红点/数字）

**交互说明**
- 点击 → 进入人事通首页（页面2）
- 待办角标实时更新

### 页面3：考勤异常消息提醒

**布局结构**
- 系统自动推送考勤异常提醒消息
- 消息卡片展示异常详情

**核心元素**
- 消息标题：考勤异常提醒
- 异常内容：漏打卡/缺勤/迟到等
- 处理按钮：「去处理」

**交互说明**
- 点击「去处理」 → 跳转对应功能页面（补卡/请假/销假）
- 每3天推送一次，直至处理完成

**数据字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| 异常类型 | 枚举 | 漏打卡/缺勤/旷工/迟到早退 |
| 异常日期 | 日期 | 发生异常的日期 |
| 处理状态 | 标签 | 未处理/已处理 |
| 推送次数 | 数字 | 已推送次数 |

### 页面5：请假申请

**布局结构**（表单页）
```
┌─────────────────────────┐
│  请假申请                │
├─────────────────────────┤
│  姓名：张三    工号：123456│
│  请假类型：[选择]        │
│    ○ 事假  ○ 病假        │
│    ○ 年假  ○ 婚假        │
│  开始时间：[日期+时间]    │
│  结束时间：[日期+时间]    │
│  请假天数：X 天（自动计算）│
│  请假事由：[输入]         │
│  附件：[上传]             │
├─────────────────────────┤
│  [提交申请]  [取消]      │
└─────────────────────────┘
```

**交互说明**
- 请假天数自动计算（结束时间-开始时间）
- 天数决定审批链：
  - ≤3天 → 直接上级审批
  - 3-7天 → 直接上级 + 间接上级
  - >7天 → 直接上级 + 间接上级 + 直属领导
- 每环节1天未审批 → 推送提醒
- 审批通过 → 自动同步夏谷系统
- 请假期间若产生考勤异常 → 触发消息提醒

**数据字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| 姓名 | 文本 | 自动带出 |
| 工号 | 文本 | 自动带出 |
| 请假类型 | 枚举 | 事假/病假/年假/婚假等 |
| 开始时间 | 日期时间 | 选择 |
| 结束时间 | 日期时间 | 选择 |
| 请假天数 | 数字 | 自动计算，只读 |
| 请假事由 | 文本 | 必填 |
| 附件 | 图片/文件 | 病假需上传证明 |
