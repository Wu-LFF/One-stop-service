# 行政通·其他（满意度/反馈/设备）— 原型方案

| # | 页面 ID | 终端 | 用途 |
|---|---------|------|------|
| 1 | `mp-qt-index` | 移动端 | 其他服务首页 |
| 2 | `mp-qt-myd` | 移动端 | 满意度调研列表 |
| 3 | `mp-qt-myd-fill` | 移动端 | 调研问卷填写 |

## 页面一：其他服务首页（mp-qt-index）

功能入口：
- 📋 满意度调研 — 填写问卷
- 💬 意见反馈 — 提建议/投诉
- 🔧 设备报修 → EAM 跳转

---

## 页面二~三：满意度调研

**调研列表（mp-qt-myd）：**
- 待填/已填 tab 切换
- 问卷卡片：标题、截止日期、状态（待填写/已提交）
- 支持匿名/实名

**问卷填写（mp-qt-myd-fill）：**
- 问卷标题 + 说明
- 题目类型：单选题、多选题、打分题、文本题
- 提交 → 自动统计

---

## 页面四~六：意见反馈

**提交表单（mp-qt-yjfk）：**
- 反馈主题
- 反馈类型：建议/投诉/BUG/其他
- 反馈内容（多行文本）
- 图片附件（最多3张）
- 联系方式

**处理规则：**
- 普通建议 → 行政专员1个工作日受理
- 投诉类 → 自动流转部门负责人
- 超时未处理 → 推送上级管理员

**记录列表（mp-qt-yjfk-list）：** 全部/处理中/已完成 tab
**详情（mp-qt-yjfk-detail）：** 反馈内容 + 处理进度 + 回复记录

---

## 页面七：设备报修（mp-qt-sbbx）— EAM 跳转

说明页：由组长申请，上班时间员工手机处于关机状态
→ 跳转 EAM 系统

---

## PC 端管理

**调研管理（pc-qt-myd）：**
- 问卷列表 → 创建问卷 → 发布/关闭
- 数据统计（图表模拟）
- 匿名/实名切换

**反馈管理（pc-qt-yjfk）：**
- 反馈列表 → 受理 → 回复 → 关闭
- 超时预警标识

---

## Portal 配置

**问卷配置（portal-qt-myd）：** 题目库管理、问卷模板
**反馈分类配置（portal-qt-yjfk）：** 分类管理、处理部门/负责人配置、处理时限设置
