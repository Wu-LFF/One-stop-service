## 📂 文件规范

### 目录结构

```
03-原型方案/
├── README.md                 # 模块索引
├── 人事通/                   # 人事通模块
│   ├── 人事通.md
│   └── 人事通.html
├── 行政通/                   # 行政通模块（含4个子模块）
│   ├── 行政通.html           # 统一入口（全模块合并）
│   ├── 行政通-安全板块.md/html
│   ├── 行政通-生活板块.md/html
│   ├── 行政通-福利服务.md/html
│   └── 行政通-其他.md/html
├── 生产通/                   # 生产通模块
│   ├── 生产通.md
│   └── 生产通.html
├── 制造资讯/                 # 制造资讯模块
│   ├── 制造资讯.md
│   └── 制造资讯.html
├── 数据服务/                 # 数据服务模块
│   ├── 数据服务.md
│   └── 数据服务.html
├── {模块名}/                 # 其他模块（后续添加）
│   └── ...
```

### 命名规则

```
{模块名}-{子模块名}.md      # 原型方案文档
{模块名}-{子模块名}.html     # 可交互 HTML 原型
{模块名}.html                # 统一入口（可选）
```

### 原型方案文档 (.md) 包含

- 页面清单（含终端类型：移动端/PC端/门户）
- 每个页面的布局结构、核心元素、交互说明、数据字段
- 三端交互汇总

### 交互原型 (.html) 规范

- 三端合一（m-page / pc-page / portal-page）
- 移动端使用 `mNav()` 导航，`mp-` 前缀 ID
- PC 端使用 `data-pc` 属性 + `pcNav()`
- 门户使用 `data-portal` 属性 + `portalNav()`
- 所有页面需通过 `validate-prototype` 断链验证
