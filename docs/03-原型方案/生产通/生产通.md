# 生产通 — 原型方案

> 基于飞书工作台（Feishu）+ 若依（RuoYi）流程引擎，MES系统对接

## 涉及角色

| 角色 | 涉及功能 |
|------|---------|
| 一线员工 | MES报工、件资查询、报工明细查询、仓库扫描、件资异常上报、员工意见箱 |
| 班组长 | 报工确认（初审） |
| 课长 | 报工确认（审核） |
| 生管经理 | 报工审核（终审） |

### 页面1：生产通首页

**布局结构**（自上而下）
```
┌─────────────────────────┐
│  生产通                  │
│  制造生产服务统一入口      │
│  报工 · 查询 · 异常上报   │
├─────────────────────────┤
│  ┌──────┐ ┌──────┐      │
│  │ 报工  │ │ 查询  │      │
│  │ 板块  │ │ 板块  │      │
│  ├──────┤ ├──────┤      │
│  │ 其他  │ │      │      │
│  │ 板块  │ │      │      │
│  └──────┘ └──────┘      │
└─────────────────────────┘
```

**核心元素**
- 顶部：模块名称 + 简介
- 3个板块入口卡片（报工/查询/其他）
- 各入口显示子功能概要

**交互说明**
- 点击板块卡片 → 进入对应板块首页

## 数据字段汇总

| 实体 | 核心字段 |
|------|---------|
| 报工记录 | 员工姓名、工号、班组、报工日期、工序、产量、工时、状态（待确认/已确认/已审核/已驳回） |
| 审批链 | 提交→班组长确认→课长审核→生管经理终审 |
| 扫描记录 | 条码、物料名称、操作类型（入库/出库）、操作时间、操作人 |
| 件资明细 | 工序、单价、完成数、小计金额、扣款项、实发合计 |
| 样鞋 | 编号、类型、归属部门、状态（制作中/已入库/领用中/已报废） |
| 异常上报 | 异常类型、发生时间、涉及工序、描述、处理状态 |
| 意见反馈 | 意见类型、标题、内容、处理状态 |
