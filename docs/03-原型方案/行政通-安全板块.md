## 页面一：安全板块首页（mp-aq-index）

### 布局结构

顶部标题栏"安全服务" → 功能入口网格（卡片式布局，2列）→ 底部 Tab 导航

### 核心元素

- [ ] **顶部栏**：标题"安全服务"，右侧消息图标
- [ ] **功能入口卡片**（2列网格）：
  - 物品放行（图标：📦）→ 跳转特预约
  - 人员放行（图标：🚶）→ 跳转特预约
  - 来访预约（图标：🤝）→ 跳转特预约
  - 安全随手拍（图标：📷）→ 进入上报页
  - 安全巡更打卡（图标：📍）→ 进入打卡页（仅安保员可见）
- [ ] **底部导航**：首页、消息、我的

### 交互说明

- 点击功能卡片 → 跳转对应功能页（特预约类跳转外部小程序，自建类跳转内部页面）
- 巡更打卡入口需根据用户角色判断是否显示（仅安保员角色可见）

## 页面二：物品放行（mp-aq-wpfx）— 特预约跳转

### 布局结构

说明页 → 确认跳转按钮

### 核心元素

- [ ] **服务说明**：物品放行说明文字
- [ ] **跳转按钮**：前往特预约办理
- [ ] **温馨提示**：当天有效，逾期作废

### 交互说明

- 点击"前往办理" → 调用飞书跳转 API 打开特预约小程序
- 点击返回 → 回到安全板块首页

（人员放行 mp-aq-ryfx、来访预约 mp-aq-lfyy 结构与物品放行一致，仅文案不同）

---

## 页面三：安全随手拍 — 上报（mp-aq-sspt）

### 布局结构

顶部标题"安全隐患上报" → 表单区域 → 底部提交按钮

### 核心元素

- [ ] **分类选择**：下拉选择隐患分类（如：消防安全、用电安全、设备安全、环境安全、其他）
- [ ] **拍照上传**：拍照/相册选择，最多 3 张
- [ ] **隐患描述**：多行文本输入，限 500 字
- [ ] **自动定位**：显示当前位置，支持手动调整
- [ ] **联系电话**：自动读取当前用户手机号，可修改

### 交互说明

- 拍照支持实时拍摄和从相册选择
- 定位默认读取 GPS 位置，定位失败时提示手动输入
- 提交 → loading → 成功/失败提示 → 跳转上报记录列表
- 提交后推送消息至安全管理部负责人

### 数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| category | string | 隐患分类 |
| images | string[] | 图片 URL 列表，最多 3 张 |
| description | string | 隐患描述，限 500 字 |
| location | object | {lat, lng, address} |
| phone | string | 联系电话 |
| status | string | 上报待确认 / 已确认整改中 / 已整改完成 |

### 布局结构

顶部标题"我的上报" → Tab 切换（全部/待处理/已完成）→ 上报列表

- 下拉刷新列表

## 页面五：安全随手拍 — 上报详情（mp-aq-sspt-detail）

### 布局结构

顶部标题"上报详情" → 图片轮播 → 信息区域 → 处理进度

### 核心元素

- [ ] **图片轮播**：全屏查看上报图片
- [ ] **信息展示**：分类、描述、定位、上报时间、联系电话
- [ ] **处理进度条**：已上报 → 已受理 → 已整改
- [ ] **整改回复**：安全管理部的整改回复内容（如有）
- [ ] **补充说明**：底部可继续补充文字/图片

### 交互说明

- 如果当前用户是安全管理部且状态为"待处理"，显示"受理"按钮
- 受理后显示"整改回复"输入框

## 页面六：安全巡更打卡（mp-aq-xgdk）

### 布局结构

顶部标题"安全巡更" → 当前任务区 → 打卡操作区 → 今日记录

### 核心元素

- [ ] **当前任务信息**：今日巡查路线名称、计划点位总数、已完成点位
- [ ] **打卡操作区**：
  - 当前点位名称
  - 拍照记录（可选）
  - 巡查情况选择（正常/异常）
  - 异常描述（选异常时显示）
  - 打卡按钮
- [ ] **今日打卡记录列表**：已打卡点位及时间

### 交互说明

- 进入页面自动定位并识别最近巡查点位
- 打卡时记录：点位ID + 时间 + GPS定位 + 巡查情况 + 照片（可选）
- 打卡成功 → 震动反馈 + 提示音 → 自动切换到下个点位
- 所有点位完成 → 显示"今日巡更已完成"
- 异常情况打卡后，自动推送消息至安全管理部

### 数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| pointId | string | 巡查点位 ID |
| pointName | string | 点位名称 |
| patrolTime | datetime | 打卡时间 |
| location | object | {lat, lng} |
| status | enum | normal / abnormal |
| note | string | 异常描述（异常时必填） |
| photo | string | 现场照片（可选） |

## 页面七：安全巡更 — 打卡记录（mp-aq-xgdk-list）

### 布局结构

顶部"巡更记录" → 日期选择 → 记录列表

### 核心元素

- [ ] **日期选择器**：查看指定日期的巡更记录
- [ ] **统计概览**：应巡点位 / 已巡点位 / 异常点位
- [ ] **记录列表**：每条显示点位名称、打卡时间、状态（正常/异常）

### 交互说明

- 默认显示今日记录
- 日期切换刷新列表
- 点击记录跳转详情（地图路线视图）

---

## 页面八：PC — 随手拍管理列表（pc-aq-sspt）

### 布局结构

顶部搜索/筛选栏 → 表格列表 → 分页

### 核心元素

- [ ] **筛选条件**：状态（全部/待处理/已整改）、分类、日期范围
- [ ] **表格**：编号、隐患分类、上报人、上报时间、状态、操作列
- [ ] **操作按钮**：受理、处理完成
- [ ] **导出**：支持导出 Excel

### 交互说明

- 点击行 → 展开详情或弹窗查看
- 受理 → 状态变更为"已受理"，推送消息给上报人
- 处理完成 → 填写整改说明 → 状态变更为"已整改"

---

## 页面九：PC — 巡更记录查看（pc-aq-xgdk）

### 布局结构

顶部选择路线/日期 → 统计卡片 → 点位列表 + 地图视图

### 核心元素

- [ ] **统计卡片**：应巡点数、已巡点数、完成率、异常数
- [ ] **点位列表**：点位名称、计划时间、实际打卡时间、状态
- [ ] **地图视图**：路线可视化，点位标记颜色区分状态（绿=正常、红=异常、灰=未巡）

### 交互说明

- 点位列表和地图视图联动，点击点位高亮显示
- 异常点位标记醒目，点击可查看详情

---

## 页面十：Portal — 巡更点位/路线配置（portal-aq-xgdk）

### 布局结构

左侧路线列表 → 右侧点位编辑区

### 核心元素

- [ ] **路线管理**：新增/编辑/删除巡查路线
- [ ] **点位管理**：每个路线下配置点位（名称、排序、GPS坐标）
- [ ] **安保员分配**：将路线分配给指定安保员
- [ ] **打卡记录查看**：按路线/人员/日期筛选

---

## 页面十一：Portal — 随手拍分类配置（portal-aq-sspt）

### 布局结构

分类列表 → 编辑区

### 核心元素

- [ ] **分类管理**：新增/编辑/删除隐患分类
- [ ] **负责人配置**：每个分类指定处理负责人/部门
- [ ] **响应时效**：每个分类可配置处理时限
