# 需求文档 — One-stop_service

## 项目简介

制造与物流园区一站式服务平台 — 构建统一身份认证、线上办事、审批协同、数据服务的综合平台。

## 项目背景

制造和物流板块现有近 7000 名员工，其中大部分一线操作员未配备与集团办公人员一致的钉钉及 OA 账号，导致运营管理存在多重痛点：

- **系统孤岛**：各项服务分散于暖心宝、TMS、鞋服MES 等多个平台，员工需记忆多个登录入口和操作流程，跨系统协作不便
- **线下审批**：纸质审批流程耗时久，跨部门协同效率低，一线操作员缺乏便捷线上办理渠道
- **员工体验**：频繁系统切换和复杂操作增加员工负担，一线操作员难以便捷享受线上服务
- **数据分散**：分散数据难以整合分析，管理层无法获取实时全面的运营数据，一线操作数据收集困难

行业趋势方面，数字化、一体化管理已成为制造和物流园区运营的主流方向，头部企业纷纷搭建统一服务平台破解管理分散、效率低下等问题。

## 项目目标

以构建高效协同、数据驱动的制造与物流园区一站式服务体系为核心：

1. **统一门户**：打造一站式服务门户，实现报修、报工、查工资等高频事项一次登录、全程在线办理
2. **统一身份认证**：构建独立于钉钉/OA 的统一身份认证与权限体系，覆盖一线操作员
3. **审批线上化**：推动全流程审批事项线上化、标准化，打通跨部门、跨层级协同链路
4. **工单闭环**：建立工单闭环管理机制，减少线下流转与人工干预
5. **数据服务**：实现全业务链条数据互通共享，支撑园区智能决策、风险预警与业务创新

## 功能需求

### 模块一：统一身份认证与权限管理

- [ ] 用户注册与登录（支持账号密码、手机验证码等方式）
- [ ] 角色管理（管理员、部门主管、一线操作员等）
- [ ] 权限控制（菜单权限、数据权限、操作权限）
- [ ] 与现有钉钉/OA 系统的集成或替代方案

### 模块二：统一服务门户

- [ ] 门户首页（聚合高频服务入口、公告通知）
- [ ] 报修服务（提交报修申请、查看进度）
- [ ] 报工服务（工时上报、工时查询）
- [ ] 工资查询（个人工资条查看）
- [ ] 公告/消息通知

### 模块三：审批流程管理

- [ ] 流程模板配置（请假、加班、报销、采购等）
- [ ] 审批发起（表单填写、附件上传）
- [ ] 审批流转（多级审批、会签、或签）
- [ ] 审批记录与追踪

### 模块四：工单闭环管理

- [ ] 工单创建与分派
- [ ] 工单处理与状态流转
- [ ] 工单验收与评价
- [ ] 工单统计与报表

### 模块五：数据服务

- [ ] 数据看板（核心运营指标可视化）
- [ ] 报表生成（自定义报表、定时导出）
- [ ] 数据集成（打通暖心宝、TMS、鞋服MES 等现有系统）
- [ ] 风险预警与决策支持

## 非功能需求

- [ ] 性能：支持 7000+ 用户并发访问，页面加载时间 < 3 秒
- [ ] 安全：等保二级及以上，数据加密传输与存储，操作日志审计
- [ ] 兼容性：支持主流浏览器（Chrome、Edge），移动端适配
- [ ] 可用性：系统可用性 ≥ 99.5%，支持 7×24 小时运行
- [ ] 易用性：界面简洁直观，适配一线操作员使用习惯
