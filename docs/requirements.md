# 需求文档 — One-stop_service

## 项目简介

制造与物流园区一站式服务平台 — 基于飞书+若依技术架构，构建统一身份认证、线上办事、审批协同、数据服务的综合平台。

## 项目背景

制造和物流板块现有近 7000 名员工，其中大部分一线操作员未配备与集团办公人员一致的钉钉及 OA 账号，导致运营管理存在多重痛点：

- **系统孤岛**：各项服务分散于暖心宝、TMS、鞋服MES 等多个平台，员工需记忆多个登录入口和操作流程，跨系统协作不便
- **线下审批**：纸质审批流程耗时久，跨部门协同效率低，一线操作员缺乏便捷线上办理渠道
- **员工体验**：频繁系统切换和复杂操作增加员工负担，一线操作员难以便捷享受线上服务
- **数据分散**：分散数据难以整合分析，管理层无法获取实时全面的运营数据，一线操作数据收集困难

## 项目目标

以构建高效协同、数据驱动的制造与物流园区一站式服务体系为核心：

1. **统一门户**：基于飞书工作台，打造一站式服务门户，实现高频事项一次登录、全程在线办理
2. **流程引擎驱动**：基于若依流程引擎，打通跨部门、跨层级协同链路
3. **工单闭环**：建立工单闭环管理机制，减少线下流转与人工干预
4. **数据贯通**：实现全业务链条数据互通共享，支撑园区智能决策

## 技术架构

- **前端**：飞书（Feishu）统一协同入口
- **后端**：若依（RuoYi）流程引擎
- **系统对接**：夏谷（HR主数据）、暖心宝（生活服务）、TMS（安全通行）、EAM（设备运维）、鞋服MES（生产数据）

## 分阶段目标

| 阶段 | 时间 | 重点 |
|------|------|------|
| 试点 | 2026 | 聚焦泉州园区，人事通全模块+行政通/生产通核心功能 |
| 推广 | 2027 | 拓展其他园区，全模块覆盖，数据服务上线 |
| 全覆盖 | 2028 | 覆盖全员，90%+业务流程线上化，AI智能化 |

## 六大核心模块

### 模块一：人事通

> 详见 [02-业务需求/HR人事模块/README.md](02-业务需求/HR人事模块/README.md)

- [ ] **考勤板块**：补卡、请假、销假（对接夏谷）
- [ ] **异动板块**：入职指引、调动、离职申请、离职手续（含电子签章）
- [ ] **其他板块**：工牌/厂服补领、福利券、工资确认、工资查询、考勤确认、考勤查询、扣款确认
- [ ] **消息提醒**：考勤异常每3天推送员工一次

### 模块二：行政通

> 详见 [02-业务需求/行政模块/README.md](02-业务需求/行政模块/README.md)

- [ ] **安全板块**：物品放行、人员放行、来访预约、安全随手拍、安全巡更（RFID/NFC打卡）
- [ ] **生活板块**：住宿申请（回传暖心宝）、超标住宿申请、宿舍报修、宿舍水电查询、报餐、家属卡申请、车位申请
- [ ] **其他板块**：困难补助、红心向党、四点半学堂、幼儿园补贴、员工福利、意见反馈、满意度调研
- [ ] **IT服务**：电脑/账号/网络问题报修

### 模块三：生产通

> 详见 [02-业务需求/生产模块/README.md](02-业务需求/生产模块/README.md)

- [ ] **报工板块**：MES报工、报工确认、报工审核（对接MES）
- [ ] **查询板块**：仓库扫描、报工明细查询、件资查询
- [ ] **其他板块**：样鞋管理、设备报修

### 模块四：制造资讯

- [ ] 公告/制度：管理员后台发布，按"最新+未读"排序，员工查看学习
- [ ] 文化天地：课程、社团活动、安全指南、服务视频

### 模块五：数据服务

- [ ] 个人数据看板（系统自动采集个人/团队/业务数据）
- [ ] 团队管理看板
- [ ] 业务数据分析

### 模块六：我的（个人中心）

- [ ] 个人信息：查看个人档案
- [ ] 账户设置：密码修改、我的皮肤（界面主题）
- [ ] 意见反馈：平台功能/使用体验反馈

### 跨模块功能

- [ ] **统一门户/工作台**：飞书统一入口、待办中心、消息中心、常用应用导航
- [ ] **提案改善**：合理化建议、工艺优化、降本增效提案
- [ ] **员工意见箱**：日常管理/后勤保障/制度流程等问题反馈

## 系统集成关系

| 系统 | 对接数据 | 方式 |
|------|---------|------|
| 夏谷（HR） | 人员/组织主数据、考勤、薪酬 | 定时同步 |
| 暖心宝 | 住宿、报修、水电、报餐 | 前端整合至平台 |
| TMS | 物品/人员放行、外来人员通行 | 免登跳转 |
| EAM | 设备报修/点检/保养 | 免登跳转 |
| 鞋服MES | 报工、产量、件资 | 免登跳转 |

## 非功能需求

- [ ] **性能**：支持 7000+ 用户并发访问，页面加载时间 < 3 秒
- [ ] **安全**：等保二级及以上，数据加密传输与存储，操作日志审计，分级授权
- [ ] **兼容性**：支持移动端（飞书内）和 PC 端
- [ ] **可用性**：系统可用性 ≥ 99.5%，支持高可用部署与灾备
- [ ] **易用性**：界面简洁直观，适配一线操作员使用习惯
