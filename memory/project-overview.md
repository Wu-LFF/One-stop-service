制造与物流园区一站式服务平台项目，服务近 7000 名员工。基于企业微信 E10 技术底座，采用"应用商店 + 节点精细管控"模式。

**项目路径**: e:\VSCode\One-stop_service

**核心模块**:
- 人力通（考勤、请假、异动、离职、工资）
- 办事通（报修、订餐、住宿、来访预约、安全巡查）
- 协同通（全流程审批、工单闭环）
- 数据通（数据看板、报表、风险预警）

**分阶段规划**: 2026 试点泉州园区 → 2027 推广 → 2028 全面覆盖

**系统集成**: 暖心宝、TMS、EAM、鞋服 MES、HR 系统

**预算**: ~3000 万，预期回收期 3.5 年

**Why**: 系统孤岛（暖心宝/TMS/鞋服MES）、线下纸质审批低效、一线操作员无钉钉/OA账号、数据分散难以支撑决策。

**How to apply**: 项目内所有需求讨论、原型设计和 PRD 输出应围绕这四大模块展开，遵循 [docs/requirements.md](docs/requirements.md) 中定义的范围，注意分阶段推进策略。
