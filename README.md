## 目录结构

```
One-stop_service/
├── src/                    # 源代码
├── docs/                   # 文档
│   ├── requirements.md     #   需求文档（总纲）
│   ├── architecture.md     #   架构设计
│   ├── decisions/          #   架构决策记录 (ADR)
│   ├── 01-蓝图方案/        #   原始蓝图方案

│   │   ├── HR人事模块/     #     人事通（考勤/薪资/异动等）
│   │   ├── 行政模块/       #     行政通（住宿/报修/福利等）
│   │   ├── 生产模块/       #     生产通（报工/件资等）
│   │   └── 通用模块/       #     公告/制度/文化等跨模块功能
│   ├── 03-原型方案/        #   （待产出）原型方案
```
