# Organize Docs — 文档自动归类

将 docs/ 目录下新增的松散文件按类型自动归类到对应子目录。

## 触发方式

- 在对话中输入 `使用 organize-docs`、`/organize-docs` 或 `归类文档`

## 步骤

### 步骤 1：扫描

扫描 docs/ 根目录下的松散文件（不在任何子目录中的文件），列出所有待归类文件。

### 步骤 2：分类

按以下规则将文件归类到对应子目录：

| 文件特征 | 目标目录 |
|----------|----------|
| 文件名含"蓝图""方案""规划"或 `.docx` 且不含"需求""流程" | `01-蓝图方案/` |
| 文件名含"需求""流程""业务""功能"或 `.xlsx` / `.csv` | `02-业务需求/` |
| 文件名含"原型"或".rp" / ".axure" | `03-原型方案/` |
| 文件名含"PRD""产品需求" | `04-PRD/` |
| 图片 (`.png` / `.jpg` / `.jpeg` / `.gif`) | `02-业务需求/` 对应模块 |
| PDF 文档 | `01-蓝图方案/` |
| 无法识别的文件 | 列出给用户，询问归属 |

### 步骤 3：用户确认

列出归类方案供用户确认，确认后执行移动。

### 步骤 4：提交 Git

```bash
git add docs/
git commit -m "归类文档：{文件名}"
```

## 注意事项

- 只处理 docs/ 根目录下的松散文件，不移动已归类到子目录的文件
- 移动前必须让用户确认归类方案
- 如果文件是图片，需结合对话上下文判断归属哪个模块（人事/行政/生产/通用）
